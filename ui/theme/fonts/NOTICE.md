# fonts bundled with anamnesis

## Special Elite

- file: `SpecialElite-Regular.woff2` (converted losslessly to WOFF2 from `SpecialElite-Regular.ttf` in the google/fonts repository, `apache/specialelite/`)
- copyright: Copyright (c) 2010 by Brian J. Bonislawsky DBA Astigmatic (AOETI). All rights reserved.
- licence: Apache License, Version 2.0 — full text in `LICENSE-SpecialElite.txt`
- designer: Astigmatic

It is bundled locally (instead of loaded from a font CDN) so that anamnesis works offline and makes no network request to render text.
